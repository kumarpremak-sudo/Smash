# Badminton Project Rules

1. **Detailed Functional Analysis:** Even for small changes in the application code, always perform a detailed functional analysis before executing.
2. **Structural Database Changes:** Whenever making structural changes to how data is linked in the database, systematically trace and verify every related CRUD operation (Create, Read, Update, Delete) across the codebase before concluding the work. Always perform a detailed ripple-effect analysis across all workflows.
